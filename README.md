# 🌸 Queens Of Change Foundation - NGO Website

A responsive and modern NGO website built using **HTML, CSS, and JavaScript**.  
This project represents an initiative focused on **women empowerment, menstrual health awareness, education, and community development**.

## 📌 Features

- Fully responsive design (mobile, tablet, desktop)
- Modern UI with smooth animations
- Interactive navigation menu (hamburger menu)
- Scroll animations using JavaScript
- Impact counter animation
- Volunteer registration form (frontend)
- Donation section UI
- Clean and professional NGO layout

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox + Grid + Animations)
- JavaScript (DOM manipulation + events)
- Font Awesome icons
- Google Fonts (Poppins)
